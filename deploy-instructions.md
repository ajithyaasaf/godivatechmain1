# Vercel Deployment Guide

## Architecture
The application is deployed on Vercel as a unified single-project setup:
1. **Frontend**: Static React bundle generated by Vite (`dist/public`)
2. **API**: Serverless functions in `api/index.ts` automatically handled by Vercel for all `/api/*` requests.

## Key Files
- `vercel.json`: Configures SPA fallbacks, internal `/api/(.*)` routing to the serverless function, and static caching.
- `api/index.ts`: Entry point for Vercel Serverless Function.
- `server/app.ts`: Core Express configuration and route handling.

## Environment Variables
Ensure the following are set in the Vercel Dashboard:
- `FIREBASE_PROJECT_ID`
- `FIREBASE_API_KEY`
- `CLOUDINARY_CLOUD_NAME`
- `CLOUDINARY_API_KEY`
- `CLOUDINARY_API_SECRET`
- `SESSION_SECRET`
